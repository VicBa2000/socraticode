================================================================================
  SOCRATICODE - QUICKSTART
================================================================================

This fork layers a socratic pedagogical system on top of OpenCode. Everything
that OpenCode does on its own (base CLI, agent loop, TUI, sessions, DB
schema, etc.) is kept intact — this quickstart does NOT modify any of it.

The only things this quickstart installs are the fork-specific additions:
  - An interactive setup wizard for configuring Ollama (Local or Cloud).
  - A `socraticode` global command (shell alias).
  - The pedagogical profile DB (auto-created on first run, no action needed).

OpenCode's own install flow (the `install` script in this directory)
is untouched and not called from here.


REQUIREMENTS
  - Bun 1.3 or later  (https://bun.sh)
  - Git
  - Optional: Ollama installed and running if you want local models
    (https://ollama.com)


PART A — OPENCODE BASE (standard, do this once)

  These two commands are just standard OpenCode / Bun project setup.
  Nothing socratic is being installed yet.

    git clone https://github.com/VicBa2000/socraticode.git
    cd socraticode
    bun install

  That's it for the base. Go to PART B.


PART B — FORK-SPECIFIC INSTALL (one script)

  A single script installs everything the fork adds on top of OpenCode:
    - Runs the SocraticCode setup wizard (interactive: Ollama Local / Cloud).
    - Adds the `socraticode` global command (shell alias).
  It does NOT touch any OpenCode internals.

  Linux / macOS (bash or zsh):
       ./socratic-install.sh

  Windows (PowerShell):
       .\socratic-install.ps1
     If execution policy blocks it the first time:
       Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
       .\socratic-install.ps1

  Windows (Git Bash / MSYS2 / Cygwin):
       ./socratic-install.sh

  When done, reload your shell (or open a new terminal) so the new
  `socraticode` command is picked up:
       source ~/.bashrc        # or ~/.zshrc on zsh
       . $PROFILE              # PowerShell

  Verify:
       socraticode --version


FIRST RUN

  socraticode

  You'll see a calibration dialog. Press a number 1-5 to pick your level,
  or ESC for the default (3 - Intermediate). After that you're at the prompt.


BASIC USAGE

  Inside the TUI:

    - Type your question/task and the mentor responds based on your level.
    - Slash commands:
        /level 3           change level (1-5)
        /mode productive   switch to productive mode (less scaffolding)
        /mode learn        switch back to learning mode
        /profile           show your full pedagogical profile
        /journal           show your progress (weekly / monthly)
        /teach closures    enter Feynman mode (you explain, Socratic pushes back)
    - Arrow up / down with the prompt empty scrolls the conversation.


ONE-SHOT RUN (no TUI)

  socraticode run -m ollama/qwen3:4b       "your question"
  socraticode run -m ollama-cloud/minimax-m2 "your question"


BENCHMARK A MODEL (recommended before committing to one)

  socraticode benchmark ollama/qwen3:4b
  socraticode benchmark ollama-cloud/minimax-m2

  Runs 5 probes (availability, instruction-following, JSON, tool-call,
  context-recall) and scores the model's fitness for socratic use.


RECOMMENDED MODELS

  Local:   qwen3:4b (minimum), gemma4 (recommended), qwen2.5-coder:32b (premium)
  Cloud:   claude-opus-4, gpt-5, gemini-1.5-pro, minimax-m2, any cloud


NOT RECOMMENDED

  llama3.2:3b, qwen2.5:3b, tinyllama, phi-3-mini — too small to handle
  OpenCode's agent prompt. They hallucinate made-up tool names.


WHAT THE FORK CREATES ON DISK (auto, no manual step)

  Config  (setup wizard writes):
     Linux / macOS:  ~/.config/socraticode/socraticode.json
     Windows:        %USERPROFILE%\.config\socraticode\socraticode.json

  Data  (first TUI run creates + auto-migrates):
     Linux / macOS:  ~/.local/share/socraticode/
                       ├─ opencode-local.db   (sessions / messages — from OpenCode)
                       ├─ socraticode.db      (pedagogical profile — added by the fork)
                       ├─ log/dev.log         (runtime logs)
                       └─ snapshot/           (session git snapshots)
     Windows:        %LOCALAPPDATA%\socraticode\   (same layout)

  Nothing else is installed globally and no external services are
  required beyond your chosen LLM provider (Ollama Local or Cloud).
  The socratic DB schema auto-applies on startup — no manual migration.


POWER-USER ENV VARS (optional overrides added by the fork)

  SOCRATICODE_FORCE_LITE=1
     Force the text-tool harness (markdown tool list, strip skills,
     smaller prompts). Use for tiny local models that claim to support
     tools but hallucinate names.

  SOCRATICODE_FORCE_STRONG=1
     Force the full socratic prompt path (HINT_META, complex directives,
     native tool_calls). Use to override auto-detection when you know
     your model is stronger than the classifier thinks.

  Set inline before the command, e.g.:
     Linux / macOS:  SOCRATICODE_FORCE_LITE=1 socraticode
     Windows PS:     $env:SOCRATICODE_FORCE_LITE="1"; socraticode


STANDALONE BINARY (optional, for distributing without Bun)

  The fork install script sets up a shell alias that calls Bun on every
  launch. If you prefer a compiled standalone binary (slightly faster
  startup, no Bun required at runtime):

       bun run --cwd packages/opencode build --single

  Binary output:
       packages/opencode/dist/socraticode-linux-x64/bin/opencode
       packages/opencode/dist/socraticode-darwin-arm64/bin/opencode
       packages\opencode\dist\socraticode-windows-x64\bin\opencode.exe

  Put the binary on your PATH under the name `socraticode` (symlink on
  Linux / macOS, copy + rename on Windows) — OpenCode's own `install`
  script is for downloading prebuilt OpenCode binaries and is not
  needed here.


RESET YOUR PROFILE (wipe calibration + session history)

  Linux / macOS:
       rm ~/.local/share/socraticode/opencode-local.db
       rm ~/.local/share/socraticode/socraticode.db

  Windows PowerShell:
       Remove-Item "$env:LOCALAPPDATA\socraticode\opencode-local.db"
       Remove-Item "$env:LOCALAPPDATA\socraticode\socraticode.db"

  The first DB stores sessions/messages; the second stores the socratic
  profile (level, weaknesses, strengths, streak). Delete both for a
  clean slate.


UNINSTALL THE FORK ADDITIONS

  1. Remove the global alias:

     Linux / macOS: open ~/.bashrc (or ~/.zshrc) and delete the line that
     starts with `alias socraticode=`.

     Windows PowerShell: open `$PROFILE` in a text editor and delete the
     block between the `# >>> socraticode (fork install) >>>` and
     `# <<< socraticode (fork install) <<<` markers.

  2. Delete the DBs and config (see RESET section above, plus):

     rm ~/.config/socraticode/socraticode.json
     Remove-Item "$env:USERPROFILE\.config\socraticode\socraticode.json"

  3. Delete the cloned repo.

  OpenCode itself is untouched by any of this.
